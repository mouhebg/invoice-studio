# Invoice Studio

A responsive invoice generator for self-employed professionals, designed with the Mo's Plans visual identity.

## Features

- Live invoice preview
- Print or save as PDF
- Automatic line-item, discount, tax, payment, and balance calculations
- Invoice status and overdue tracking
- Saved invoice history and receivables totals
- Invoice duplication and recurring draft preparation
- Logo and brand accent customization
- Client email handoff and optional online payment links
- Local JSON backup and restoration
- Responsive mobile and A4 print layouts

## Privacy

Invoice and customer information is stored in the browser on the user's device. This project does not include cloud synchronization, payment processing, or automatic email delivery.

## Run locally

Serve the repository with any static web server, then open `index.html`.

```bash
python3 -m http.server 8000
```
